# Star Wars Planets: filtros com Context API

Tabela com os planetas de Star Wars (SWAPI) e filtros combináveis, com estado global via Context API e Hooks.

> Projeto desenvolvido durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/) (2023).

## Funcionalidades

- Busca de planetas pela API pública SWAPI
- Filtro por nome em tempo real
- Filtros numéricos combináveis por coluna, operador (maior que, menor que, igual a) e valor
- Remoção de filtros um a um ou todos de uma vez

## Stack

React 18 · TypeScript · Context API · Hooks · Vite · Vitest · React Testing Library · Cypress

## Como rodar

```bash
npm install
npm run dev
```

Testes:

```bash
npm test
```
